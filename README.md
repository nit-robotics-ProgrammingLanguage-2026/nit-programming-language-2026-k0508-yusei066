# 課題0508 総合: AIの実装と自分の実装を比べる

## 仕様
入力された int 整数 n について:
- n が **負** のとき「Error」
- n が **0** のとき「No」
- n が正のとき，次の3つを **この順に，独立して** 判定し，当てはまるものを **つなげて** 表示する
  - 3 の倍数なら「Up」
  - 5 の倍数なら「Go」
  - 7 の倍数なら「!!」
- どれにも当てはまらなければ「No」

例: 15 → `UpGo` / 21 → `Up!!` / 105 → `UpGo!!` / 4 → `No`

## 課題
1. **まず自力で** `main.c` を書け(AIを使わず書いてよい．使うなら ai_log.txt に書く)．
2. 次に，**この仕様の文章だけをAIに渡して**，プログラムを書かせ，それを `ai.c` として保存せよ．
3. `main.c` と `ai.c` を **いろいろな入力で比べ**，出力が食い違う入力を `diff_inputs.txt` に1行1つ書け．
   - 食い違いが **ない** ときは，1行目に `なし` と書く．
   - 食い違う入力を書いたときは，その入力では **ai.c が仕様と違う** ことになる．

ヒント: 「0 のとき」「負のとき」「7の倍数のとき」のような境界や特殊なケースを重点的に調べよ．
自分のテストを作る方法は自由だが，シェルの `for` やファイルからの入力を使うと楽である．

## 提出するファイル
- `main.c` : 自力で書いたプログラム
- `ai.c` : AIに書かせたプログラム
- `diff_inputs.txt` : 食い違う入力
- `ai_log.txt`

## 採点について
- push すると GitHub Actions が自動採点します。結果は Actions のログと、フィードバック用の Pull Request に出ます。
- 採点は **プログラムを実行した結果** で行います。何度でも push して再採点できます。
- `ai_log.txt`(AI利用ログ)も採点対象です(10点)。AIを使ってもかまいません。ただし **AIの答えを自分で確かめること** が課題の目的です。
